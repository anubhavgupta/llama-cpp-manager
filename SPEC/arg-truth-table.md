# Arg truth table — how the argv vector is built

Human view of `SPEC/arg-truth-table.json`, generated by `node tools/parity/spec-reconcile.js`.
Derivation keys: `a` static read of `parity-baseline`, `b` `fixtures/**` recordings, `c` the
independent model pass. Anything that is not a plain agreement carries a `resolution`; the full
matrix is in `SPEC/CONSISTENCY.md`.

args.push runs in source order in one flat array; argv order is part of the contract

Always appended: --host, --port, -fit (derivations a+c). Recorded client-built bodies: 4.

## Where the recordings are silent

- a flag that every recorded launch emits has no negative observation, so the condition that gates it is invisible (see alwaysEmitted and flags[].absentIn)
- the order of flags that no recorded launch emitted cannot be derived; only flags present in the recordings are listed
