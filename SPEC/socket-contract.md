## Where the recordings are silent

- socket.io reconnection behaviour: no recording disconnects and reconnects the page
- whether the client re-joins split log payloads is invisible: the recordings show pane line counts and payload sizes, not the app-side handler
- event emission order inside the server is only observable as it arrived on one recorded socket
- the socket path/namespace string is recorded as the page URL, not as the server-side namespace
